# Emails Scraping

A Python-based email scraping and processing tool.

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/MOULAYID/emails-scraping.git
   cd emails-scraping
   ```

2. Set up virtual environment:
   ```bash
   python -m venv .venv
   .\.venv\Scripts\activate
   ```
